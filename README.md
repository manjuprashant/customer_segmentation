# Customer Segmentation Dashboard

## Project Overview
This project analyzes customer demographics and behavioral characteristics to identify meaningful customer segments.

## Dataset
Kaggle Customer Segmentation Dataset:
https://www.kaggle.com/datasets/vetrirah/customer

## Objectives
- Clean customer data
- Analyze customer characteristics
- Create customer segments
- Build an interactive Power BI dashboard
- Generate business insights

## Tools Used
- Python
- Pandas
- Power BI
- GitHub

## KPI Metrics
- Total Customers
- Average Age
- Average Family Size
- Average Work Experience

## Dashboard Visuals
1. Segment Distribution
2. Segment vs Age Category
3. Segment vs Profession
4. Segment vs Marital Status
5. Segment vs Graduation Status
6. Top Customer Table

## Interactive Filters
- Gender
- Profession
- Segmentation
- Spending Score
- Graduated
- Ever Married

## Key Insights
- Customer behavior differs significantly across segments.
- Profession and age influence customer segmentation.
- Spending score helps identify high-value customers.
