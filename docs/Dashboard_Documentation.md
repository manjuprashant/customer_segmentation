# Dashboard Documentation

## Overview
This Power BI dashboard provides customer segmentation insights using demographic and behavioral variables.

## KPI Cards
- Total Customers
- Average Age
- Average Family Size
- Average Work Experience

## Visualizations

### Segment Distribution
Displays customer counts across segments.

### Segment vs Age Category
Shows distribution of segments by age groups.

### Segment vs Profession
Analyzes profession-based customer segmentation.

### Segment vs Marital Status
Examines customer segments by marital status.

### Segment vs Graduation Status
Shows segmentation patterns by educational background.

### Top Customer Table
Displays customer-level information.

## Filters
- Gender
- Profession
- Segmentation
- Spending Score
- Graduated
- Ever Married
